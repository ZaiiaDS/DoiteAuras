================================================================
/dshatter -- НАСТРОЙКА ЭФФЕКТА SHATTER
================================================================

Общее
-----
Слэш-команда для настройки эффекта shatter и частиц без правки
файлов и без интерфейса. Значения хранятся в SavedVariables,
переживают релог, релоад и обновление аддона.

Изменения вступают в силу со СЛЕДУЮЩЕГО shatter'а. Активный в
момент правки эффект догуливает по старым значениям, чтобы кадр
не дёргался.

Две эквивалентных команды: /dshatter (основная) и /dsh (короткая).


Список команд
-------------
/dshatter                       Показать все параметры
                                Изменённые от дефолта помечены (modified)

/dshatter <key> <value>         Установить один параметр

/dshatter reset                 Сбросить ВСЕ параметры к дефолту

/dshatter reset <key>           Сбросить один параметр

/dshatter preset save <name>    Сохранить текущий набор как пресет

/dshatter preset load <name>    Применить сохранённый пресет

/dshatter preset delete <name>  Удалить пресет

/dshatter preset list           Показать все пресеты

/dshatter help                  Справка


Параметры: ОСКОЛКИ ИКОНКИ
-------------------------
Все числовые, кроме pTex. Значения вне диапазона -- команда
откажет с "out of range".

grid
  Дефолт: 5
  Диапазон: 3-8
  Размер сетки NxN. 5 = 25 осколков, 4 = 16, 6 = 36, 8 = 64.
  Больше = детальнее, но дороже по CPU.

scatterMin
  Дефолт: 400
  Диапазон: 0-3000
  Минимальное расстояние старта осколка от его слота (пиксели).
  Больше = осколки появляются дальше.

scatterMax
  Дефолт: 400
  Диапазон: 0-3000
  Максимальное расстояние. Если scatterMin = scatterMax, все
  стартуют с одного радиуса.

stagger
  Дефолт: 0.25
  Диапазон: 0-1
  Разброс задержки старта осколков, доля от длительности.
  0 = все летят одновременно, 0.5 = сильно разлетаются по времени.

waveAmp
  Дефолт: 20
  Диапазон: 0-200
  Размах волны в полёте (пиксели). 0 = осколки летят по прямой.

waveFreqMin
  Дефолт: 1.5
  Диапазон: 0-20
  Минимум колебаний за полёт. 3 = осколок виляет три раза по пути.

waveFreqMax
  Дефолт: 3.0
  Диапазон: 0-20
  Максимум. Каждому осколку даётся случайная частота в этом
  диапазоне.

pieceStart
  Дефолт: 0.333
  Диапазон: 0.05-1
  Стартовый размер осколка (доля от финального).
  1/3 = осколок в три раза меньше иконки, 1 = сразу полноразмерный.

dirCone
  Дефолт: 60
  Диапазон: 5-180
  Полуугол конуса, когда задан Direction в Edit (left/right/up/down).
  В градусах. 60 = плюс-минус 60 градусов, 180 = все 360.


Параметры: ЧАСТИЦЫ
------------------
pTex
  Дефолт: spark
  Значения: spark | gold | white
  Текстура частиц.
    spark -- мягкая искра из кастбара (по умолчанию)
    gold  -- Blizzard-спаркл подсветки кнопки, золотистая
    white -- чистый белый пиксель (квадрат любого цвета)

pCount
  Дефолт: 50
  Диапазон: 0-200
  Число частиц. 0 = отключить частицы совсем.

pSizeMin
  Дефолт: 4
  Диапазон: 1-64
  Минимальный размер частицы (пиксели).

pSizeMax
  Дефолт: 14
  Диапазон: 1-64
  Максимальный размер.

pDistMin
  Дефолт: 300
  Диапазон: 0-3000
  Минимальный радиус старта частицы.

pDistMax
  Дефолт: 400
  Диапазон: 0-3000
  Максимальный радиус.

pDelay
  Дефолт: 0.30
  Диапазон: 0-1
  Разброс задержки старта, доля от длительности.
  0 = все частицы стартуют мгновенно.

pFlight
  Дефолт: 0.70
  Диапазон: 0.05-1
  Длительность полёта одной частицы, доля от длительности.
  Обычно pDelay + pFlight <= 1, иначе часть искр обрежется.

pAlphaMin
  Дефолт: 0.30
  Диапазон: 0-1
  Минимальная базовая прозрачность частицы.

pAlphaMax
  Дефолт: 0.80
  Диапазон: 0-1
  Максимальная.


Примеры
-------
Посмотреть что сейчас:
    /dshatter

Крупные редкие выразительные искры:
    /dshatter pSizeMin 8
    /dshatter pSizeMax 20
    /dshatter pCount 30

Быстрые короткие частицы (вспышка):
    /dshatter pDelay 0
    /dshatter pFlight 0.3

Плотное облако, искры летят пока осколки уже в сборе:
    /dshatter pDelay 0.4
    /dshatter pFlight 0.6

Много мелких белых точек:
    /dshatter pTex white
    /dshatter pSizeMin 2
    /dshatter pSizeMax 4
    /dshatter pCount 100

Только осколки, без частиц:
    /dshatter pCount 0

16 крупных осколков с плавными волнами:
    /dshatter grid 4
    /dshatter pieceStart 0.5
    /dshatter waveAmp 40
    /dshatter waveFreqMax 1.5


Пресеты
-------
Хранится ПОЛНЫЙ набор параметров (все ключи кроме версии). При
загрузке применяется поверх текущих настроек.

Сохранить текущее состояние:
    /dshatter preset save favourite

Настроить что-то другое:
    /dshatter grid 6
    /dshatter pCount 100

Вернуться к любимому:
    /dshatter preset load favourite

Удалить пресет:
    /dshatter preset delete favourite

Посмотреть все пресеты:
    /dshatter preset list

ВАЖНО: имя пресета не может содержать пробелы -- команда парсит
аргументы по пробелам. Используй fastburst, subtle-v2 и т.п.


Программный API (из /run)
-------------------------
    /run DoiteShatter.SetParam("grid", 4)
    /run print(DoiteShatter.GetParam("waveAmp"))
    /run DoiteShatter.SavePreset("boss")
    /run DoiteShatter.LoadPreset("boss")
    /run DoiteShatter.ListPresets()
    /run DoiteShatter.DeletePreset("boss")
    /run DoiteShatter.ResetParam("pCount")
    /run DoiteShatter.ResetParam(nil)  -- всё

Удобно для применения набора изменений одной макросной строкой:
    /run DoiteShatter.SetParam("grid",4) DoiteShatter.SetParam("pCount",80) DoiteShatter.SetParam("pTex","white")


Куда сохраняется
----------------
Настройки: DoiteAurasDB.shatter.<ключ>
Пресеты:   DoiteAurasDB.shatterPresets.<имя>

Всё в SavedVariables. Ручная правка файла сохранки тоже работает,
но осторожно: поле _version нужно для миграций, не удаляй его.


Ограничения
-----------
- Значения ограничены диапазонами. Ввести grid 20 нельзя --
  увидишь "out of range [3..8]".
- Активный shatter не подхватывает изменения. Нужно кастануть
  заново, чтобы увидеть новый вид.
- Имена пресетов не могут содержать пробелы.
- pTex чувствителен к регистру: spark, gold, white -- строчными.


Диагностика
-----------
Значения не применяются? Проверь что миграция отработала:
    /run local s=DoiteAurasDB.shatter print("ver="..tostring(s._version).." pTex="..tostring(s.pTex))

Должно вернуть ver=2. Если ver=1 -- миграция не запускалась,
набери /dshatter (это вызывает GetCfg, который мигрирует).

Параметр не находится:
    /dshatter
покажет список всех валидных ключей.

Состояние после серии экспериментов непонятное:
    /dshatter reset
всё к дефолтам. Пресеты при этом сохраняются.
