# `/dshatter` — настройка эффекта shatter

Слэш-команда для настройки эффекта shatter и частиц без правки файлов и без интерфейса. Значения хранятся в `SavedVariables`, переживают релог, релоад и обновление аддона.

**Изменения вступают в силу со следующего shatter'а.** Активный в момент правки эффект догуливает по старым значениям — чтобы картинка одного кадра не дёргалась.

Две эквивалентных команды: `/dshatter` (основная) и `/dsh` (короткая).

---

## Список команд

| Команда | Что делает |
|---|---|
| `/dshatter` | Показать все параметры и текущие значения. Изменённые от дефолта помечены `(modified)` |
| `/dshatter <key> <value>` | Установить один параметр |
| `/dshatter reset` | Сбросить **все** параметры к дефолту |
| `/dshatter reset <key>` | Сбросить один параметр |
| `/dshatter preset save <name>` | Сохранить текущий набор как пресет |
| `/dshatter preset load <name>` | Применить сохранённый пресет |
| `/dshatter preset delete <name>` | Удалить пресет |
| `/dshatter preset list` | Показать все пресеты |
| `/dshatter help` | Справка |

---

## Параметры: осколки иконки

Все числовые. Значения вне диапазона — команда откажет с `out of range`.

| Ключ | Дефолт | Диапазон | Что делает |
|---|---|---|---|
| `grid` | `5` | 3–8 | Размер сетки N×N. `5` = 25 осколков, `4` = 16, `6` = 36, `8` = 64. Больше = детальнее, но дороже по CPU |
| `scatterMin` | `400` | 0–3000 | Минимальное расстояние старта осколка от его слота (пиксели). Больше = осколки появляются дальше |
| `scatterMax` | `400` | 0–3000 | Максимальное расстояние. `scatterMin = scatterMax` = все стартуют с одного радиуса |
| `stagger` | `0.25` | 0–1 | Разброс задержки старта осколков, доля от длительности. `0` = все летят одновременно, `0.5` = сильно разлетаются во времени |
| `waveAmp` | `20` | 0–200 | Размах волны в полёте (пиксели). `0` = осколки летят по прямой |
| `waveFreqMin` | `1.5` | 0–20 | Минимум колебаний за полёт. `3` = осколок виляет три раза по пути |
| `waveFreqMax` | `3.0` | 0–20 | Максимум. Каждому осколку даётся случайная частота в этом диапазоне |
| `pieceStart` | `0.333` | 0.05–1 | Стартовый размер осколка (доля от финального). `1/3` = осколок в три раза меньше иконки, `1` = сразу полноразмерный |
| `dirCone` | `60` | 5–180 | Полуугол конуса, когда задан `Direction` в Edit (`left`/`right`/`up`/`down`). В градусах. `60` = ±60°, `180` = все 360° |

## Параметры: частицы

| Ключ | Дефолт | Диапазон | Что делает |
|---|---|---|---|
| `pTex` | `spark` | `spark` / `gold` / `white` | Текстура частиц (см. ниже) |
| `pCount` | `50` | 0–200 | Число частиц. `0` = отключить частицы совсем |
| `pSizeMin` | `4` | 1–64 | Минимальный размер частицы (пиксели) |
| `pSizeMax` | `14` | 1–64 | Максимальный размер |
| `pDistMin` | `300` | 0–3000 | Минимальный радиус старта частицы |
| `pDistMax` | `400` | 0–3000 | Максимальный радиус |
| `pDelay` | `0.30` | 0–1 | Разброс задержки старта, доля от длительности. `0` = все частицы стартуют мгновенно |
| `pFlight` | `0.70` | 0.05–1 | Длительность полёта одной частицы, доля от длительности. Обычно `pDelay + pFlight ≤ 1`, иначе часть искр обрежется |
| `pAlphaMin` | `0.30` | 0–1 | Минимальная базовая прозрачность частицы |
| `pAlphaMax` | `0.80` | 0–1 | Максимальная |

### Значения `pTex`

| Значение | Текстура | Внешний вид |
|---|---|---|
| `spark` | `Interface\CastingBar\UI-CastingBar-Spark` | Мягкая размытая искра, светлый мазок. Дефолт |
| `gold` | `Interface\Buttons\UI-Panel-MinimizeButton-Highlight` | Родная Blizzard-искра, **золотистая**. Цвет зафиксирован, vertex tint не сделает её белой |
| `white` | `Interface\Buttons\WHITE8X8` | Чистый белый пиксель, рендерится как **квадрат** любого цвета, заданного vertex tint |

## Примеры

**Посмотреть что сейчас:**
```
/dshatter
```

**Крупные редкие выразительные искры:**
```
/dshatter pSizeMin 8
/dshatter pSizeMax 20
/dshatter pCount 30
```

**Быстрые короткие частицы (вспышка):**
```
/dshatter pDelay 0
/dshatter pFlight 0.3
```

**Плотное облако, искры летят пока осколки уже в сборе:**
```
/dshatter pDelay 0.4
/dshatter pFlight 0.6
```

**Много мелких белых точек:**
```
/dshatter pTex white
/dshatter pSizeMin 2
/dshatter pSizeMax 4
/dshatter pCount 100
```

**Только осколки, без частиц:**
```
/dshatter pCount 0
```

**16 крупных осколков с плавными волнами:**
```
/dshatter grid 4
/dshatter pieceStart 0.5
/dshatter waveAmp 40
/dshatter waveFreqMax 1.5
```

## Пресеты

Хранится **полный набор** параметров (все ключи кроме версии). При загрузке применяется поверх текущих настроек.

**Сохранить текущее состояние:**
```
/dshatter preset save favourite
```

**Настроить что-то другое:**
```
/dshatter grid 6
/dshatter pCount 100
```

**Вернуться к любимому:**
```
/dshatter preset load favourite
```

**Удалить:**
```
/dshatter preset delete favourite
```

**Посмотреть все:**
```
/dshatter preset list
```

> **Важно:** имя пресета не может содержать пробелы — команда парсит аргументы по пробелам. Используй `fastburst`, `subtle-v2` и т.п.

---

## Программный API (из `/run`)

```lua
/run DoiteShatter.SetParam("grid", 4)
/run print(DoiteShatter.GetParam("waveAmp"))
/run DoiteShatter.SavePreset("boss")
/run DoiteShatter.LoadPreset("boss")
/run DoiteShatter.ListPresets()
/run DoiteShatter.DeletePreset("boss")
/run DoiteShatter.ResetParam("pCount")
/run DoiteShatter.ResetParam(nil)  -- всё
```

Удобно для применения набора изменений одной макросной строкой:

```
/run DoiteShatter.SetParam("grid",4) DoiteShatter.SetParam("pCount",80) DoiteShatter.SetParam("pTex","white")
```

## Куда сохраняется

| Что | Где |
|---|---|
| Настройки | `DoiteAurasDB.shatter.<ключ>` |
| Пресеты | `DoiteAurasDB.shatterPresets.<имя>` |

Всё в `SavedVariables`. Ручная правка файла сохранки тоже работает, но осторожно: поле `_version` нужно для миграций, не удаляй его.

---

## Ограничения

- Значения ограничены диапазонами. Ввести `grid 20` нельзя — увидишь `out of range [3..8]`.
- Активный shatter не подхватывает изменения. Нужно кастануть заново.
- Имена пресетов не могут содержать пробелы.
- `pTex` чувствителен к регистру: `spark`, `gold`, `white` — строчными.

---

## Диагностика

**Значения не применяются?** Проверь что миграция отработала:

```
/run local s=DoiteAurasDB.shatter print("ver="..tostring(s._version).." pTex="..tostring(s.pTex))
```

Должно вернуть `ver=2`. Если `ver=1` — миграция не запускалась, набери `/dshatter` (это вызывает `GetCfg`, который мигрирует).

**Параметр не находится?** `/dshatter` покажет список всех валидных ключей.

**Состояние после серии экспериментов непонятное?** `/dshatter reset` — всё к дефолтам. Пресеты при этом сохраняются.
